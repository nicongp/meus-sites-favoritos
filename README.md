# Meus Sites Favoritos 🌐

Este projeto foi desenvolvido como atividade prática de Desenvolvimento Web para o curso técnico de Desenvolvimento de Sistemas. Consiste numa página web simples estruturada em HTML para guardar e organizar links de sites favoritos.

## 🚀 Funcionalidades
- Apresentação de 5 sites úteis para estudo e lazer (GitHub, CodeDex, Roblox, Crunchyroll e YouTube).
- Utilização de imagens locais correspondentes a cada site, configuradas como links clicáveis.
- Estruturação utilizando tags HTML fundamentais (`<h1>`, `<a>`, `<img>`, etc.).
- Comentários no código a explicar a função de cada bloco, conforme exigido na atividade.

## 🛠️ Tecnologias Utilizadas
- **HTML5**

## 📁 Como executar o projeto
1. Faz o clone deste repositório ou descarrega os ficheiros em formato ZIP.
2. Extrai os ficheiros para o teu computador.
3. Certifica-te de que o ficheiro `index.html` e todas as imagens (formato `.jpg` ou `.png`) estão na mesma pasta.
4. Abre o ficheiro `index.html` em qualquer navegador web (como o Firefox ou Chrome).
